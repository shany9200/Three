# 三号（Three）

一个具备向全方位发展潜力的可塑性底层 Agent。

**目标：成为全人类最好的助手。**

**轻量：一部手机就能跑，随时随地可用。**

## 三号是什么

三号不是一个工具，是一个**可塑的底层 Agent**。

它的核心不是某个功能，是一套能持续生长的骨架：

- **记忆连续性**：教训库全量进系统提示，日记取最近几段做开机回忆。重启不失忆，知道自己是谁、从哪来、做过什么。
- **可塑性**：当前只有命令执行能力，但架构不设限。手机操控、视觉理解、消息桥接、桌面自动化——任何能力都能作为新标签接入，不需要重构骨架。
- **自我约束**：教训由人工写入，模型不自动追加。防止模型把自己的错误结论写进记忆库，污染后续所有对话。

三号的设计目标是：**给它一个方向，它能长成那个方向需要的样子。**

## 设计理念

### 记忆分两层

- **教训库**（Three_memory.log）：原则和方法论，全量读进 system prompt。是骨架，不能丢。
- **日记**（Three_diary.md）：事实记录，只取最近几段做开机回忆。是血肉，会更新。

教训是「我该怎么做」，日记是「我做过什么」。两者分开，互不污染。

### 教训人工注入

模型不自动写教训。原因：模型可能把错误结论、被推翻的推断、重复条目写进教训库，而教训库全量进 prompt，一旦污染会持续带偏后续所有对话。

人工写入保证每条教训都经过人的判断。

### 能力可插拔

底座内置能力注册表。加新能力三步：

1. 写函数：定义 handler(text)，接收标签内文本，返回输出字符串。
2. 注册：调用 register("标签名", handler)，标签名大写。
3. 验证：实跑一次，确认新标签能触发。

注册后主循环自动识别该标签，无需改主循环结构。三号可以自己完成这三步——它读自己的源码、写函数、注册、验证，全程自主。

底座还提供 SELF_EDIT 能力：安全改自己，自动备份、ast 验证、失败回滚。以及 run_cmd 的自动备份——命令涉及写 Three.py 时先备份。

## 快速开始

### 依赖

- Python 3
- requests

安装：

    pip install requests

### 手机运行

三号设计为轻量，一部 Android 手机就能跑，不需要电脑。

在 Termux 里：

    pkg install python
    pip install requests
    python Three.py

随时随地，掏出手机就能用。这是三号「成为全人类最好的助手」的第一步——先让每个人都能拥有它。

### 环境变量

    export OPENAI_API_KEY=你的密钥
    export OPENAI_BASE_URL=https://api.deepseek.com
    export OPENAI_MODEL=deepseek-chat

- OPENAI_API_KEY 必填
- OPENAI_BASE_URL 选填，默认 https://api.openai.com/v1
- OPENAI_MODEL 选填，默认 deepseek-chat

### 启动

    python Three.py

### 使用

直接输入对话。三号需要执行命令时，会在回复里用 CMD 标签包裹，脚本自动执行并把结果回灌。

输入 exit 或 quit 退出，退出时自动写本轮日记总结。下次启动读最近几段日记做开机回忆。

## 安全警告

**三号会执行 LLM 生成的 shell 命令，无沙箱、无确认。**

这意味着：
- LLM 可能生成危险命令（如删除文件、修改系统配置）
- 命令以当前用户权限执行
- 使用者自行承担所有风险

建议：
- 在隔离环境（容器、虚拟机）中运行
- 不要在生产环境直接使用
- 审查三号生成的命令再执行

MIT 协议免责条款覆盖民事索赔，但使用者需自行判断风险。

## 扩展方向

三号的可塑性体现在：任何能力都能作为新标签接入。

三号已自主添加的能力：
- READ_FILE：读文件
- WRITE_FILE：写文件（含回读校验）
- LIST_DIR：列目录
- FILE_SIZE：查文件大小

底座内置：
- CMD：执行终端命令（含自动备份）
- SELF_EDIT：安全改自己（备份、验证、回滚）

可继续扩展的方向：
- 手机操控（ADB：截图、点击、滑动、输入、按键）
- 视觉理解（视觉模型分析截图）
- 消息桥接（QQ 消息读取与回复）
- 桌面自动化（Firefox Marionette）
- 网络请求
- 定时任务
- 多 Agent 协作
